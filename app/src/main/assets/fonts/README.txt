Game font: Kanit by Cadson Demak, SIL Open Font License 1.1 (https://openfontlicense.org).
The build workflow downloads Kanit-SemiBold.ttf, Kanit-BlackItalic.ttf and OFL.txt into this folder.
To build locally, download those files from https://fonts.google.com/specimen/Kanit and put them here.
If they are missing the game still runs, using the phone's default font.
